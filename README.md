# PST-QP-TVF-FLC

Hardware-in-the-loop experiment video for the paper:

**Fully Distributed Quadratic Programming for Prescribed-Time Optimal Time-Varying Formation and Flexible Containment Control of Fully Heterogeneous MASs**

The experiment consists of one virtual leader, three simulated UAVs (leaders 1–3), and three real Mecanum-wheeled UGVs (followers 4–6).
